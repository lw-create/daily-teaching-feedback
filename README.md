# 每日教学反馈生成器

一款专为教师设计的轻量级教学反馈工具，帮助老师快速生成专业、格式统一的学生教学反馈，轻松发送给家长。

## 功能特性

### 核心功能
- **四大反馈板块**：学习内容、学生状态、作业、教师评价，结构清晰
- **基础信息**：日期、科目、学生姓名，自动填充
- **实时预览**：填写过程中即时预览最终反馈效果，可直接复制发送

### 学生管理
- **学生名字记忆**：输入过的学生姓名自动保存，下次通过下拉框快速选择
- **数据持久化**：所有数据存储在浏览器本地，无需登录，无需联网

### 课程管理（一对多）
- **课程录入**：填写"第几节 + 对应时间"（如：第1节 08:00-08:45），保存后自动加入下拉框
- **多课程关联**：一个学生可关联多节课，以标签形式展示，支持单独删除
- **课程复用**：保存的课程在不同学生、不同日期的反馈中均可重复使用

### 引导式输入
- **学生状态引导选择**：多维度选项（课堂参与、专注度、理解程度等），点击即填入，避免每次重新描述
- **教师评价引导选择**：多维度评价模板，快速选择合适的评语方向
- **历史记录**：每个板块的输入历史自动保存，可一键复用

### AI 辅助
- **AI 提示语**：内置专业提示词模板，复制后发给 AI 即可生成格式统一的反馈
- **AI 润色**：支持先自由描述（不限制字数），再通过 AI 润色优化语言表达

### 今日反馈记录
- **自动保存**：每次生成的反馈自动保存到当日记录
- **批量复制**：支持一键复制当天所有反馈，条与条之间用分隔线隔开
- **单条管理**：每条反馈可单独复制或删除
- **日期切换**：切换日期查看不同日期的反馈记录

### 移动端支持
- **PWA 应用**：支持添加到手机桌面，像原生 App 一样使用
- **响应式设计**：完美适配手机屏幕，随时随地填写反馈

## 使用方法

### 在线使用
直接在浏览器中打开 `daily-teaching-feedback.html` 即可使用。

### 手机桌面安装
1. 在手机浏览器中打开工具页面
2. 点击浏览器的「分享」或「菜单」按钮
3. 选择「添加到主屏幕」
4. 桌面会出现「教学反馈」图标，点击即可直接使用

### 本地部署
```bash
# 进入项目目录
cd daily-teaching-feedback

# 启动本地服务器（任选一种）
python3 -m http.server 8080
# 或
npx serve

# 浏览器访问
# http://localhost:8080/daily-teaching-feedback.html
```

## 技术栈

- **纯前端实现**：HTML + CSS + JavaScript，零依赖
- **数据存储**：浏览器 localStorage，无需后端
- **PWA**：支持离线使用和桌面安装
- **响应式设计**：适配桌面和移动端

## 数据说明

所有数据存储在浏览器的 localStorage 中，包括：
- `teaching_students` — 学生姓名列表
- `teaching_courses` — 课程信息列表
- `teaching_today_YYYY-MM-DD` — 每日反馈记录
- 各板块的历史输入记录

清除浏览器缓存会导致数据丢失，请注意备份。

## 适用场景

- 课后给家长发送教学反馈
- 记录每日教学情况
- 跟踪学生学习状态
- 多学生、多课程的教学管理
